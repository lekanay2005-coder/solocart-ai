## Decimen Optical Transfer — MIT

The mobile app's optical transport (the fountain encoder/decoder and frame
envelope under `apps/morrow-mobile/src/vendor/decimen/`) derives from
**Decimen Optical Transfer** by Anas Abubakar:
<https://github.com/Pendia/Decimen-Optical-QR-Transfer/tree/v0.3.0>, pinned to
commit `29cba8fa25dd160c8b6aa18fe3b48fbc5bde2e36`.

The extracted core is used unchanged (`LTEncoder`, `LTDecoder`, deterministic
logarithm, robust-soliton distribution, wire-stable frame index derivation) —
cross-engine determinism is part of the wire format, so these math routines
must not be swapped for platform approximations. Newer Decimen releases need a
license review before adoption. The full permission notice ships beside the
source at `apps/morrow-mobile/src/vendor/decimen/LICENSE`:

## @noble/curves and @noble/hashes — MIT

Ed25519 signing and SHA-256 for the offline protocol, in three places: the
server (`node_modules`, declared in `package.json`), the browser halves
(`public/vendor/noble/`, re-vendored by `npm run vendor`, license files copied
beside the code), and the mobile app (`apps/morrow-mobile`, `deviceKeys.ts`).
By Paul Miller, MIT — see `public/vendor/noble/curves/LICENSE`.
